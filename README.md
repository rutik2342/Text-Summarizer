# Text Summarizer

A text summarization web application built using FastAPI and Hugging Face T5 Transformer.

## Project Overview

This project takes user-provided text and generates a concise summary using a trained T5 Transformer model.

## Technologies Used

- Python
- FastAPI
- Hugging Face Transformers
- T5 Transformer
- PyTorch
- HTML
- CSS
- JavaScript

## Features

- Text input through a web interface
- Automatic text summarization
- T5 Transformer-based summarization
- FastAPI backend
- Simple and user-friendly interface
